# EXP-CA-006：新しいポートで CC 23 → Channel EQ Master Gain を GUI で学習し、3 つの値で確かめる

詳細は [英語版](EXP-CA-006-learn-on-new-port.en.md)。

- 日時：2026-10-21 09:01–09:09 JST。条件は EXP-CA-005 と同じで、新しい仮想ポート `logicctl-gen` を使った。
- うまくいった手順（Apple ガイド ctls71c31855 に沿う）：①割り当て画面で「(ゾーンなし)」を表示 ②本物のマウスで Gain を少し動かす（押すだけ・背面からのドラッグでは登録されない）③⌘L ④ 64・70・76・82 を 0.4 秒おきに送る ⑤⌘L で終了。
- 結果：96 → AX 363（+12.3 dB）、32 → 121（−11.9 dB）、64 → 242（+0.2 dB）で、3 回とも予測どおり。MIDI 送信（ログ）・割り当て（AX と設定ファイルのコピー）・値（AX）を別々に確認した。
- 1 回目の学習は、割り当て画面が直前に「VPots / Surround Position」を表示していたため、行がその（有効でない）モードに入り反応しなかった。その行は削除した。
- 設定ファイルのコピーでは、新しい行の +0x56 は 0xffff（「ゾーンなし」の行と同じ）、リスト 6 の識別子は (0x454d4147, 0, 0xec)・順番 0 で、静的解析の予測どおり。
- 後片付け：Option クリックで Gain を 0.0 dB（240）に戻した。学習した行は今後のテスト用に残した。送信ツールは停止。
- 仮説：学習した行は割り当て画面で表示中のゾーン・モードに入る（確信度：中）。+0x56 はゾーンの参照で 0xffff が「ゾーンなし」（確信度：中〜低）。
