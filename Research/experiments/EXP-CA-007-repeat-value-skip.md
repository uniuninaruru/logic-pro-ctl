# EXP-CA-007：途中で値を動かしても、同じ CC 値の 2 回目は捨てられる（PLAN-CA-005 T1）

詳細は [英語版](EXP-CA-007-repeat-value-skip.en.md)。ピックアップ OFF で、96 → +12.3 dB。画面で 0.0 dB に戻してから 96 を再送しても 0.0 dB のまま（予測どおり）。97 は +12.7 dB に反映。比べる相手は「対象の今の値」ではなく「割り当てに保存された前回の値」。ピックアップは ON に戻した。
