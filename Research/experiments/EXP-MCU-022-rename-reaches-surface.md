# EXP-MCU-022: トラック名の変更が MCU の表示に届くか

| 項目 | 内容 |
|---|---|
| 日時 | 2026-10-02 13:05–13:15 JST |
| Logic バージョン | 12.3.1 (6682) |
| macOS バージョン | 27.0 (26A5416b) |
| Logic Remote バージョン | 該当なし |
| テストプロジェクト | LogicCLI-Test.logicx（トラック10 + St Out + Master = 12ストリップ） |
| 初期状態 | `logicd` を再起動して MCU に接続済み（世代 4）。表示は第 1 バンク（トラック 1〜8）。トラック 5 の名前は `Trk05` |
| 1つの操作 | Logic のトラックヘッダーで、トラック 5 の名前を `Trk05` から `Zed5` に変更して確定する。それ以外は変えない |
| 期待する変化 | 仮説どおりなら、MCU の上段 LCD のトラック 5 のセルが `Zed5` になり、`--expect-name Trk05` の照合が `target_mismatch` になる |
| 再現回数 | 1 回（変更 → 確認 → 元に戻す） |

## 目的

`track mute 5 on --expect-name Trk05` のような照合は、「Logic が名前の変更をサーフェスへ送る」ことを前提にしています
（[docs/target-contract.md](../../docs/target-contract.md)）。この前提を確かめる実験です。
送られなければ、バンクを動かさずに表示中のセルを読む照合は、変更後も古い名前を見て通ってしまいます。

## 手順と観察

| 段階 | 操作 | 観察 |
|---|---|---|
| 0 | `logicctl track get 5 --expect-name Trk05` | 成功。`observation.session.bank_offset` は 0 |
| 1 | GUI で名前欄を `Zed5` に書き換える（入力のみ） | 画面の名前欄は編集中のまま。この時点の LCD は確認していない |
| 2 | 空き領域をクリックして確定する | — |
| 3 | `logicctl status`（LCD の生の写し） | `Piano  Audio  Bass   Synth  Zed5   Trk06  Trk07  Trk08  ` — **5 番目のセルが `Zed5`** |
| 4 | `track get 5 --expect-name Trk05` | `target_mismatch`、`observed.name` は `Zed5`。データは返さない |
| 5 | `track get 5 --expect-name Zed5` | 成功 |
| 6 | 名前を `Trk05` に戻して確定 | `track list`（完全）の名前はすべて元どおり |

- 手順 1 のあとで Return を送ったが、名前欄は編集中のまま残り、確定しなかった（操作ツールは「選択テキストに改行を設定した」と報告した）。確定は空き領域のクリックで行った。
  そのため、**入力中に LCD が更新されるか、確定で更新されるかは区別できていない**。
- 手順 3 の LCD は、バンクを動かさずに読んだ写しである。つまり名前の変更は、**サーフェスのバンクを動かさなくても表示中のセルに届いた**。

## 仮説（Hypothesis）

仮説（Hypothesis）: Logic は、表示中のストリップの名前が変わると、そのセルの LCD を更新する。
確信度: 中〜高（1 回の実験。変更前後の写しを比べた）。
根拠: 手順 3 の LCD の写し。手順 4・5 の照合結果。
反例: なし。
未検証（確信度を上げない）:
- トラックの**並べ替え・追加・削除**でも、Logic がサーフェスを更新するか。単体試験の模擬では「更新する」と仮定している。
- 表示中でないストリップの名前変更は、次にそのバンクを表示したときに反映されるはず（バンクを動かすと LCD が書き直される）。この実験では試していない。
- 名前を入力している途中の LCD の挙動。
次の検証実験: 並べ替え（トラックヘッダーのドラッグ）、トラックの追加、トラックの削除を、それぞれ別の実験として行い、
バンクを動かさずに `track get` の名前が変わるかを調べる（Undo で元に戻す。保存はしない）。

## logicctl への帰結

- `--expect-name` は、名前の変更について、バンクを動かさない読み取りで検出できた。
- 並べ替え・追加・削除での検出は**未確認**。確認できるまで、[target-contract](../../docs/target-contract.md) では
  「並べ替えなどを検出する」とは書かず、「Logic がサーフェスを更新した場合に検出する」と書く。
